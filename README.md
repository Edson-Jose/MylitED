# MylitED

Aplicativo mobile para organização de tarefas, desenvolvido com **React Native**, **Expo** e **TypeScript**.

O MylitED é um projeto em desenvolvimento criado com o objetivo de facilitar a organização de tarefas e atividades do dia a dia. O projeto também serve como prática de desenvolvimento mobile, navegação entre telas, gerenciamento de estado, autenticação e integração com serviços externos.

## 📱 Sobre o projeto

O **MylitED** começou como um aplicativo de tarefas e está sendo estruturado para oferecer uma experiência simples e organizada para o usuário.

A aplicação utiliza uma arquitetura baseada em componentes e separação de responsabilidades, mantendo as telas, rotas, hooks, estilos e demais recursos organizados dentro da pasta `src`.

## 🚀 Tecnologias utilizadas

- **React Native** — desenvolvimento da aplicação mobile
- **Expo** — ambiente e ferramentas para desenvolvimento React Native
- **TypeScript** — tipagem e organização do código
- **React Navigation** — navegação entre telas
- **Firebase** — serviços de backend e autenticação
- **Zustand** — gerenciamento de estado
- **Async Storage** — armazenamento local
- **Styled Components** — estilização dos componentes
- **Formik + Yup** — criação e validação de formulários
- **Expo Image Picker** — seleção de imagens
- **DateTimePicker** — seleção de datas e horários

O projeto atualmente utiliza Expo `~54.0.35`, React `19.1.0`, React Native `0.81.5` e TypeScript `~5.9.2`.

## ⚙️ Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/Edson-Jose/MylitED.git
```

### 2. Entrar na pasta

```bash
cd MylitED
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Iniciar o projeto

```bash
npm start
```

Também é possível utilizar:

```bash
npm run android
```

```bash
npm run ios
```

```bash
npm run web
```

> Para executar no Android ou iOS, é necessário ter o ambiente correspondente configurado. Durante o desenvolvimento também é possível utilizar o Expo Go, quando compatível com a versão do projeto.

## 🧩 Scripts disponíveis

| Comando | Função |
